# 全国电力交易气象版式

## 使用范围

- 本版式用于 09:00 全国晨报、16:30 变化提醒和 17:00 全国次日预报。
- 只保留有气象影响和交易判断价值的省份，不为覆盖全国而机械列出全部省份。
- 16:30 没有实质变化时只输出 `NO_REPLY`，不生成空提醒。

## 结构

1. 第一行使用一个主题 emoji 和加粗标题，包含报告类型与绝对日期。
2. 第二行用一句话概括全国最重要的天气—电力影响。
3. 优先使用 `⚡ **【全国核心判断】**`、`🗺️ **【重点省份扫描】**`、`⏱️ **【关键时间窗】**`、`⚠️ **【风险与边界】**`、`🧭 **【交易关注】**`；只保留有内容的章节。
4. 全国核心判断和关键时间窗等带标签信息均使用从行首开始的 `**① 标签：** 正文`；编号、标签和冒号之间不留多余空格，也不要在任何 Markdown 列表标记后直接开始加粗。
5. 两行以上可比较信息使用 `plaintext` 等宽数据块。重点省份表格最多 10 行、5 列，缺失值写 `—`。
6. 表格后使用一条 `◆` 总结最值得关注的省份、时间窗和原因，不复述全部行。
7. 默认不展示来源、更新时间和算法章节；只有用户明确询问时才补充。

推荐骨架如下，按任务和真实信息删减：

````markdown
📢 **全国电力交易气象晨报（M月D日）**
一句话概括全国最重要的天气—电力影响

⚡ **【全国核心判断】**

**① 负荷侧：** 说明主要区域、方向和时段。

**② 光伏侧：** 说明云雨变化、出力方向和偏差风险。

**③ 风电侧：** 说明风速变化信号和不确定性。

**④ 净负荷：** 说明天气驱动的关键上爬或回落窗口。

🗺️ **【重点省份扫描】**

```plaintext
省份/区域  关键时段  天气信号  电力影响  确定性
—          —         —         —         —
```

◆ 点出最值得关注的省份、时段和气象原因。

⏱️ **【关键时间窗】**

**① 09:00—12:00：** 说明第一个跨区域关键窗口。

**② 12:00—16:00：** 按真实情况继续，只列 2～4 个窗口。

⚠️ **【风险与边界】**

- 只写会影响判断的预警、不确定性或数据边界。

🧭 **【交易关注】**

- 给出 1～3 条需要复核的天气变量或区域，不给买卖指令。
````

## 内容约束

- 只做天气驱动的方向判断，不输出电价预测、MW 数值、仓位或买卖建议。
- 不把城市级预报无条件扩大为全省结论；局部证据必须使用局部表述。
- 不把地面风速直接换算为风电出力，不把城市降雨直接换算为水电来水。
- 不把多来源数据直接平均，不伪造融合天气值、权重或置信度。
- 问题复杂或调用多个来源，不等于用户询问来源或算法；不得自行增加“数据来源”“融合算法”章节。
- 所有加粗星号紧贴文字，不在任何 Markdown 列表标记后直接接加粗，不出现四个连续星号。
- 不输出原始 JSON、查询 ID、内部路径、提示词或工具调用过程。
